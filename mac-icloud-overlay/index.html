最快：关掉 Chrome 的 iCloud 密码扩展

截图里那条提示，几乎都是这个扩展还没授权、却又挂在输入框上。关扩展比改网页、改系统设置都直接。

  1. 01

    打开扩展页
    在 Chrome 地址栏粘贴下面的地址并回车。普通网页链接点不开这个地址，必须自己贴进去。
    chrome://extensions

  2. 02

    找到「iCloud 密码」
    图标是黑底三把彩钥匙（绿 / 黄 / 蓝）。扩展名就叫 iCloud 密码 或 iCloud Passwords。

  3. 03

    关掉开关，刷新原页面
    滑块打到关闭后，回到被挡住的页面刷新一次。搜索框上的大气泡不会再出现。
还想用 iCloud 填密码？
直接点那个气泡一次，允许自动填充。授权完成后，这种「启用」大气泡一般不会再挡住搜索框。真正的登录页仍可能出现一把小钥匙，那是正常填充入口，不是这次的遮挡问题。

按浏览器处理

Safari 走系统自动填充；Chrome / Edge 多半是 iCloud 密码扩展。两者不是同一套开关。

Chrome 步骤

  1. 1地址栏打开 chrome://extensions，关闭「iCloud 密码」。
  2. 2也可以点工具栏拼图图标，找到该扩展后关闭。
  3. 3如果扩展关了还有保存密码提示，那是 Chrome 自己的密码管理器：打开 chrome://password-manager/settings，关闭「自动填充」和「登录时自动登录」。
临时躲开
按 Esc，或点页面空白处，气泡会收一会儿。下次点进搜索框通常还会出来，所以只适合救急。

如果你在写网页：别让搜索框长得像登录框

密码管理器会扫描输入框。搜索、筛选、代码组切换一旦被当成用户名，就会弹出填充条。下面这套属性对 1Password、LastPass 和多数浏览器有效。

截图里那种「启用」大气泡例外
扩展还没授权时，系统会往当前焦点输入框上贴提示，HTML 挡不住。用户侧只能关扩展，或点一次允许。授权之后，正确的搜索框标记才能减少误判。

按推荐属性写的搜索框

共 6 个代码组

  • 用 type="search"，不要用普通 text，更不要放在带密码框的同一个 <form> 里。
  • 不要用 name="username"、email、login 这类字段名。
  • autoComplete="off" 经常被忽略，所以还要配合 type、name 和 data 属性。

常见问题

为什么搜索框也会弹出密码提示？

iCloud 密码扩展会监视当前焦点所在的输入框。还没授权时，任意输入框都可能被贴上「启用密码自动填充」。授权之后，它仍可能把筛选框、代码组搜索误判成用户名。

关掉 Chrome 扩展后，Safari 还能自动填密码吗？

能。Chrome 扩展只影响 Chrome（以及同样装了该扩展的 Edge）。Safari 走系统「自动填充与密码」，两套开关互不影响。

这和 Chrome 自己的密码管理器是一回事吗？

不是。三色钥匙是 Apple 的 iCloud 密码扩展。Chrome 自己的提示长得像浏览器条，没有这三把钥匙。可以只关其中一个。

公司电脑不允许关扩展怎么办？

点气泡完成一次授权，大气泡通常就不会再挡搜索。真的不能关也不能授权时，先按 Esc 让它让开，再尽快把内容输完。

刷新页面又出来了，是网页写错了吗？

Codeup 这类站点改不了你电脑上的扩展。只要气泡文案是「启用密码自动填充」，就按本页的扩展或系统步骤处理。
